# Proyecto aplicado — Reconstrucción y regularización en imágenes tomográficas

Trabajo Práctico de Métodos Computacionales, S2 2026.

## Estructura

- `ejercicio_1.ipynb` a `ejercicio_11.ipynb`: un notebook por ejercicio.
- `figuras/`: gráficos exportados desde los notebooks.
- `uso_ia.txt`: registro del uso de herramientas de IA generativa.
- `presentacion.pdf`: presentación final del trabajo.

## Dependencias recomendadas

- Python 3
- NumPy
- SciPy
- Matplotlib

Los notebooks deben poder ejecutarse de principio a fin sin errores.
